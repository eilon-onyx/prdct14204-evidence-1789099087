===== (F) PER-LINE ISOLATION (the design that keeps a mixed batch's good records) =====
A single bad LINE inside an otherwise-good object is counted and skipped, and the object still ingests
its good records — only an object that is ENTIRELY unusable is parked:
  pipeline.route_lines (pipeline.py:113-138): json.loads per line; JSONDecodeError/UnicodeDecodeError
    -> malformed += 1; continue; logs "scanner object contained malformed lines". The whole object is
    escalated to poison ONLY when non_blank > 0 and NOT records (nothing parseable at all).
  extract.extract_inventory (extract.py:846): raises ObjectParseError only when
    scan_records > 0 AND unparseable_scan_records == scan_records AND produced_nothing.
This is the lane's deliberate fix for the old Temporal lane, where one bad line poisoned the whole object.
